Command Aliases let you define custom shortcuts that execute existing commands with predefined arguments, flags, or placeholder parameters.

## Add an alias

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/alias add alias:<name> command:<command string> [delete_invoking:<on or off>]
```

  </Tab>
  <Tab>

```text
/alias add alias:deport command:ban
```

  </Tab>
</Tabs>

In this example, typing `,deport @member` automatically executes `,ban @member`. Any extra arguments typed after the alias are forwarded to the underlying command.

### Delete invoking message

You can pass `delete_invoking:on` to automatically purge the member's trigger message whenever the alias is invoked:

```text
/alias add alias:clean command:purge 50 delete_invoking:on
```

Or toggle it later with `/alias deletetrigger alias:clean state:on`.

## Dynamic argument placeholders

Embed numbered placeholders (`{0}`, `{1}`, `{2}`) to position user arguments into specific slots of your custom command template.

### Saved duration shortcut

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/alias add alias:<name> command:<template with {0}>
```

  </Tab>
  <Tab>

```text
/alias add alias:m10 command:timeout {0} 10m
```

  </Tab>
</Tabs>

Running `,m10 @member` expands to `,timeout @member 10m`.

### Role shortcut

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/alias add alias:<name> command:<template with {0}>
```

  </Tab>
  <Tab>

```text
/alias add alias:pic command:role {0} @Pic-Perms
```

  </Tab>
</Tabs>

Running `,pic @member` expands to `,role @member @Pic-Perms`.
