Invite Tracking records server joins and leaves by invite code, tracks inviter metrics (real, leaves, fake, bonus), awards milestone roles, and posts real-time join attribution notices.

## Quickstart

<Steps>
  <Step title="Enable tracking">
    Invite tracking is off by default. Turn it on with:

```text
/invites enable
```
  </Step>
  <Step title="Set a tracker channel">
    Designate where join and leave attribution messages should be posted:

```text
/invites tracker set channel:#invites
```
  </Step>
</Steps>

## Lookups & Statistics

### Member invite statistics

View total invites, leaves, fake joins, and bonus credits:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/invites user [member:<user>]
```

  </Tab>
  <Tab>

```text
/invites user member:@member
```

  </Tab>
</Tabs>

### Identify inviter

Look up who invited a specific member, which code was used, and where the invite originated:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/invites inviter [target:<user>]
```

  </Tab>
  <Tab>

```text
/invites inviter target:@member
```

  </Tab>
</Tabs>

### View invited members

List all members recruited by a specific user:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/invites invited [target:<user>] [page:<integer>]
```

  </Tab>
  <Tab>

```text
/invites invited target:@member page:1
```

  </Tab>
</Tabs>

### Active invite codes

List all active invite codes generated by a member:

```text
/invites invitecodes [member:<user>]
```

## Anti-fake invite requirements

Prevent botting and throwaway accounts from generating illegitimate invite points.

### Minimum account age

Set the minimum account age required for an invite to count as real:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/invites requiredage days:<integer>
```

  </Tab>
  <Tab>

```text
/invites requiredage days:7
```

  </Tab>
</Tabs>

Joins by accounts younger than the required age are flagged as fake invites.

### Required roles

Require members to acquire a specific verification role before their inviter is credited:

```text
/invites requiredroles [role:@Verified]
```
