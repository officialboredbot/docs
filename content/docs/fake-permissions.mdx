Fake Permissions let staff run bored's commands without holding native Discord administrative permissions. This prevents rogue moderators from abusing native Discord audit menus or bypassing the bot.

## How Fake Permissions work

When a role is granted a fake permission (such as `ban_members`), members holding that role pass bored's command checks for ban commands. However, they do not gain native Discord ban permissions in server settings, so they cannot ban members natively or through other bots.

<Callout type="warning" title="Server owner only">
Only the **server owner** can manage fake permissions.
</Callout>

## Allowed fake permissions

These are the permission identifiers recognized by bored:

- `administrator` — full command execution access.
- `ban_members` — ban and unban commands.
- `kick_members` — kick commands.
- `manage_messages` — purge, clean, and message commands.
- `moderate_members` — timeout, mute, and jail commands.
- `manage_guild` — server configuration commands.
- `manage_channels` — channel creation, deletion, and slowmode.
- `manage_roles` — role award and modification commands.
- `manage_nicknames` — nickname moderation.
- `manage_webhooks` — webhook management.
- `manage_expressions` — custom emoji and sticker management.
- `mention_everyone` — commands with mention permissions.
- `view_audit_log` — audit log viewer commands.

## Add fake permissions

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/settings fakepermissions add role:<role> permissions:<permissions>
```

  </Tab>
  <Tab>

```text
/settings fakepermissions add role:@Moderator permissions:ban_members, kick_members
```

  </Tab>
</Tabs>

## Remove fake permissions

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/settings fakepermissions remove role:<role> permissions:<permissions>
```

  </Tab>
  <Tab>

```text
/settings fakepermissions remove role:@Moderator permissions:ban_members, kick_members
```

  </Tab>
</Tabs>

## List fake permissions

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/settings fakepermissions list [role:<role>]
```

  </Tab>
  <Tab>

```text
/settings fakepermissions list role:@Moderator
```

  </Tab>
</Tabs>

If you omit the role option, bored lists all active fake permission bindings across the entire server.

## Reset all fake permissions

Clear every fake permission configured in the server:

```text
/settings fakepermissions reset
```
