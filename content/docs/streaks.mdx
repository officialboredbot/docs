Streaks incentivize active participation by challenging members to meet a daily message threshold and claim their streak daily.

## Server configuration

Configure timezone, daily message volume requirement, and reset schedules.

<Tabs items={["Enable", "Disable", "Timezone", "Reset time", "Requirement"]}>
  <Tab>

```text
/streak enable
```

  </Tab>
  <Tab>

```text
/streak disable
```

  </Tab>
  <Tab>

```text
/streak timezone timezone:<string>
```

  </Tab>
  <Tab>

```text
/streak reset reset:<string>
```

  </Tab>
  <Tab>

```text
/streak requirement messages:<integer>
```

  </Tab>
</Tabs>

Reset time supports 12-hour and 24-hour formats (such as `12 AM`, `8:30 PM`, `00:00`, and `20:30`). The requirement specifies the message quota needed before a streak can be claimed (1–1,000 messages).

## Member commands

<Tabs items={["Profile", "Claim", "Restore", "Leaderboard"]}>
  <Tab>

```text
/streak profile [member:<user>]
```

  </Tab>
  <Tab>

```text
/streak claim
```

  </Tab>
  <Tab>

```text
/streak restore
```

  </Tab>
  <Tab>

```text
/streak leaderboard
```

  </Tab>
</Tabs>

`/streak claim` unlocks as soon as the daily message target is fulfilled. Missed streaks can be repaired with `/streak restore` if the user holds restore credits within the configured grace window.

## Restores and grace period

<Tabs items={["Starting restores", "Grace window", "Grant credits"]}>
  <Tab>

```text
/streak restores amount:<integer>
```

  </Tab>
  <Tab>

```text
/streak restorewindow days:<integer>
```

  </Tab>
  <Tab>

```text
/streak grantrestore member:<user> [amount:<integer>]
```

  </Tab>
</Tabs>

Default starting credits range from `0` to `100`. The restore window can be set between `1` and `30` days.

## Reward roles

Staff with `Manage Roles` can assign milestone roles to reward continuous streaks.

<Tabs items={["Add", "Update", "Remove", "List", "Sync"]}>
  <Tab>

```text
/streak add role:<role> streak:<integer>
```

  </Tab>
  <Tab>

```text
/streak update role:<role> streak:<integer>
```

  </Tab>
  <Tab>

```text
/streak remove streak:<integer>
```

  </Tab>
  <Tab>

```text
/streak roles
```

  </Tab>
  <Tab>

```text
/streak sync
```

  </Tab>
</Tabs>

Milestone roles stack. Running `/streak sync` re-evaluates all members and reclaims roles from members whose streaks lapsed.
