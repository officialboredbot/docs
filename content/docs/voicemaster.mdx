VoiceMaster automatically creates disposable, customizable temporary voice channels (Join to Create) when a member connects to the designated generator channel. Channel owners can manage their room via slash commands or the interactive interface panel in `#interface`.

<Callout type="info" title="Owner controls">
Most day-to-day VoiceMaster management commands only work for the **current room owner**. If the owner disconnects, another active member in that channel can claim ownership with `/voicemaster claim`.
</Callout>

## First-time setup

<Steps>
  <Step title="Run `/voicemaster setup`">
    Launch the interactive setup wizard to generate the voice category layout.

```text
/voicemaster setup
```
  </Step>
  <Step title="Choose your layout">
    Select whether you want a public Join to Create channel, a private Join to Create channel, or both. bored automatically creates the required categories, interface channel, and generator channels.
  </Step>
  <Step title="Manage rooms">
    Empty temporary voice channels are automatically pruned and deleted when all members leave.
  </Step>
</Steps>

## Naming & defaults

### Default channel configuration

<Tabs items={["Name", "Bitrate", "Region", "Default Role", "Join Role"]}>
  <Tab>

```text
/voicemaster default name name:<template>
```

Variables supported: `{user.display_name}`, `{user.name}`, `{user.id}`, `{guild.name}`. Default: `{user.display_name}'s vc`.

  </Tab>
  <Tab>

```text
/voicemaster default bitrate bitrate:128
```

  </Tab>
  <Tab>

```text
/voicemaster default region region:us-east
```

  </Tab>
  <Tab>

```text
/voicemaster default role role:@Voice Access
```

  </Tab>
  <Tab>

```text
/voicemaster join role role:@In Voice
```

  </Tab>
</Tabs>

## Channel owner controls

These commands can be run by the owner of an active temporary voice channel.

### Basic channel controls

<Tabs items={["Rename", "User Limit", "Bitrate", "Status"]}>
  <Tab>

```text
/voicemaster rename name:<new name>
```

Has a 10-minute cooldown per room.

  </Tab>
  <Tab>

```text
/voicemaster limit limit:5
```

  </Tab>
  <Tab>

```text
/voicemaster bitrate bitrate:96
```

  </Tab>
  <Tab>

```text
/voicemaster status status:Chilling & Gaming
```

  </Tab>
</Tabs>

### Privacy & Access

<Tabs items={["Lock", "Unlock", "Ghost", "Unghost", "Permit", "Reject"]}>
  <Tab>

```text
/voicemaster lock
```

Prevents unauthorized users from connecting.

  </Tab>
  <Tab>

```text
/voicemaster unlock
```

Opens the room to all server members.

  </Tab>
  <Tab>

```text
/voicemaster ghost
```

Hides the channel from members without access.

  </Tab>
  <Tab>

```text
/voicemaster unghost
```

Makes the channel visible again.

  </Tab>
  <Tab>

```text
/voicemaster permit member:@member
```

Grants a specific user permission to join your locked room.

  </Tab>
  <Tab>

```text
/voicemaster reject member:@member
```

Disconnects and bans a specific user from your temporary room.

  </Tab>
</Tabs>

### Ownership controls

<Tabs items={["Claim", "Transfer"]}>
  <Tab>

```text
/voicemaster claim
```

Claim ownership if the original channel creator disconnected.

  </Tab>
  <Tab>

```text
/voicemaster transfer member:@member
```

Transfer channel ownership to another active participant.

  </Tab>
</Tabs>

## Reset & interface recovery

<Tabs items={["Reset", "Resend interface"]}>
  <Tab>

```text
/voicemaster reset
```

Clears all VoiceMaster settings and category bindings.

  </Tab>
  <Tab>

```text
/voicemaster sendinterface
```

Reposts the interactive button interface message in `#interface`.

  </Tab>
