Confessions lets members submit anonymous posts with `/confess`. Public confession posts can include vote buttons, anonymous reply threads, and staff reporting.

## Start here

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
confessions add (channel)
```

  </Tab>
  <Tab>

```text
confessions add #confessions
```

  </Tab>
</Tabs>

Bored needs view, send, embed, read history, create public thread, and send in thread permissions in the confession channel.

## Member flow

```text
/confess
```

The slash command opens a modal for the confession text. Confessions and anonymous replies cannot be empty, cannot contain links or Discord invites, and are checked against the server's confession blacklist.

Confession submissions have a `60` second cooldown. Anonymous replies have a `30` second cooldown.

## Report a confession

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text

```

  </Tab>
  <Tab>

```text

```

  </Tab>

Reports go to the configured staff report channel and include the saved anonymous subject when bored can resolve it.

## Vote buttons

<Tabs items={["Set", "View", "Reset"]}>
  <Tab>

```text
confessions emojis set (upvote emoji or none) (downvote emoji or none)
```

  </Tab>
  <Tab>

```text
confessions emojis view
```

  </Tab>
  <Tab>

```text
confessions emojis reset
```

  </Tab>
</Tabs>

Use `none`, `off`, `clear`, or similar clear words for a vote side to hide that button. `confessions emojis reset` restores the default vote buttons.

## Disable

```text
confessions disable
```

This asks for confirmation, disables anonymous confessions, and wipes the stored confession records for the server. `confessions remove` works as a compatibility alias.
