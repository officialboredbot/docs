Confessions lets members submit anonymous confessions via `/confess`. Confession posts support interactive upvote/downvote buttons, anonymous reply threads, and staff report routing.

## Setup confession channel

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/confessions add channel:<channel>
```

  </Tab>
  <Tab>

```text
/confessions add channel:#confessions
```

  </Tab>
</Tabs>

bored requires View Channel, Send Messages, Embed Links, Read Message History, and Create Public Threads in the confession channel.

## Member submission flow

```text
/confess
```

Members run `/confess` to open an anonymous confession modal. Submissions cannot be blank, cannot contain links or Discord invites, and are checked against blacklisted keywords.

## Staff report channel

<Tabs items={["Set channel", "Report confession"]}>
  <Tab>

```text
/confessions reportchannel channel:#confession-reports
```

  </Tab>
  <Tab>

```text
/confessions report confession_number:7
```

  </Tab>
</Tabs>

## Member mutes

Block abusive members from submitting anonymous confessions:

<Tabs items={["Mute", "Unmute"]}>
  <Tab>

```text
/confessions mute member:@bad-actor
```

  </Tab>
  <Tab>

```text
/confessions unmute member:@bad-actor
```

  </Tab>
</Tabs>

## Blacklisted words

Filter specific words or slurs from anonymous confessions and replies:

<Tabs items={["Add", "Remove", "List", "Clear"]}>
  <Tab>

```text
/confessions blacklist add word:<phrase>
```

  </Tab>
  <Tab>

```text
/confessions blacklist remove word:<phrase>
```

  </Tab>
  <Tab>

```text
/confessions blacklist list
```

  </Tab>
  <Tab>

```text
/confessions blacklist clear
```

  </Tab>
</Tabs>

```text
/confessions disable
```
