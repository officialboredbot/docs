bored's suggestion engine allows community members to pitch ideas, vote via custom reaction emojis, engage in attached discussion threads, and route submissions through optional staff moderation queues.

## Setup and routing

Configure destination channels for suggestions and staff review.

<Tabs items={["Setup", "Channel", "Review queue", "Config"]}>
  <Tab>

```text
/suggest setup channel:<channel> [review_channel:<channel>]
```

  </Tab>
  <Tab>

```text
/suggest channel channel:<channel>
```

  </Tab>
  <Tab>

```text
/suggest review channel:<channel>
```

  </Tab>
  <Tab>

```text
/suggest config
```

  </Tab>
</Tabs>

If a review channel is configured, submissions will wait for staff approval before publishing to the public suggestions channel.

## Member submission

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/suggest submit suggestion:<string>
```

  </Tab>
  <Tab>

```text
/suggest submit suggestion:Add a dedicated media channel for photography
```

  </Tab>
</Tabs>

## Voting emojis and threads

<Tabs items={["Voting reactions", "Discussion threads"]}>
  <Tab>

```text
/suggest emoji upvote:<string> downvote:<string>
```

  </Tab>
  <Tab>

```text
/suggest threads enabled:<on|off>
```

  </Tab>
</Tabs>

Enabling discussion threads automatically spawns a dedicated Discord thread under every published suggestion.

## Staff moderation

Review and update the status of submitted suggestions. The `target` accepts the suggestion ID or message link.

<Tabs items={["Approve", "Deny", "Consider", "In Progress", "Pending", "Custom status"]}>
  <Tab>

```text
/suggest approve target:<id>
```

  </Tab>
  <Tab>

```text
/suggest deny target:<id>
```

  </Tab>
  <Tab>

```text
/suggest consider target:<id>
```

  </Tab>
  <Tab>

```text
/suggest progress target:<id>
```

  </Tab>
  <Tab>

```text
/suggest pending target:<id>
```

  </Tab>
  <Tab>

```text
/suggest status status:<string> target:<id>
```

  </Tab>
</Tabs>
