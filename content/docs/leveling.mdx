Leveling tracks server message activity, awarding XP, unlocking reward roles, and powering server rankings and live crownboards.

Members can gain XP once every `60` seconds, awarding a random base of `15` to `25` XP before server and role multipliers are applied.

## Quickstart

<Steps>
  <Step title="Enable leveling">
    Leveling is disabled by default. Enable it with:

```text
/levels enable
```
  </Step>
  <Step title="Check your rank">
    View your current rank card, level, and XP progress.

```text
/levels rank
```
  </Step>
</Steps>

## XP rate & multipliers

### Global server rate

Scale all XP gains across the server by a global multiplier:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/levels setrate multiplier:<multiplier>
```

  </Tab>
  <Tab>

```text
/levels setrate multiplier:1.5
```

  </Tab>
</Tabs>

### Role XP multipliers

Grant bonus XP multipliers to specific roles (e.g. Server Boosters, VIPs, or Patrons).

<Tabs items={["Add/Set", "List", "Remove", "Reset"]}>
  <Tab>

```text
/levels multiplier role role:<role> rate:<multiplier>
```

Example: `/levels multiplier role role:@Booster rate:2.0`

  </Tab>
  <Tab>

```text
/levels multiplier list
```

  </Tab>
  <Tab>

```text
/levels multiplier remove role:<role>
```

  </Tab>
  <Tab>

```text
/levels multiplier reset
```

  </Tab>
</Tabs>

## Reward roles

Automatically award roles when members reach specific milestone levels.

### Add a reward role

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/levels add role:<role> rank:<level>
```

  </Tab>
  <Tab>

```text
/levels add role:@Level 5 rank:5
```

  </Tab>
</Tabs>

### Update or remove reward roles

<Tabs items={["Update", "Remove", "List"]}>
  <Tab>

```text
/levels update role:<role> rank:<level>
```

  </Tab>
  <Tab>

```text
/levels remove rank:<level>
```

  </Tab>
  <Tab>

```text
/levels roles
```

  </Tab>
</Tabs>

### Stack reward roles

Control whether members accumulate all previous reward roles or only keep their single highest role:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/levels stackroles setting:<on or off>
```

  </Tab>
  <Tab>

```text
/levels stackroles setting:off
```

  </Tab>
</Tabs>

### Sync reward roles

Re-evaluate and backfill reward roles for all server members:

```text
/levels sync
```

## Level-up notifications

### Custom message

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/levels message text:<template>
```

  </Tab>
  <Tab>

```text
/levels message text:Congrats {user.mention} on reaching level {level.new_rank} in {guild.name}!
```

  </Tab>
</Tabs>

### Dispatch destination

Control where level-up alerts are posted:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/levels messagemode mode:<pm|context|none|channel> [channel:<channel>]
```

  </Tab>
  <Tab>

```text
/levels messagemode mode:channel channel:#level-up
```

  </Tab>
</Tabs>

Modes: `pm` (direct message), `context` (channel where the member sent the message), `channel` (designated channel), or `none` (silent).

## Ignore channels & roles

Prevent XP gain in spam or bot channels:

<Tabs items={["Ignore target", "List ignored"]}>
  <Tab>

```text
/levels ignore [channel:<channel>] [category:<category>] [role:<role>]
```

  </Tab>
  <Tab>

```text
/levels list
```

  </Tab>
</Tabs>

## Leaderboards & Crownboards

### View leaderboard

```text
/levels leaderboard
```

### Live updating crownboard

Post an automatically updating top-10 leaderboard embed in a dedicated channel:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/levels crownboard channel:<channel>
```

  </Tab>
  <Tab>

```text
/levels crownboard channel:#levels
```

  </Tab>
</Tabs>

Refreshes automatically every **10 minutes**.

## Manual adjustments & moderation

Modify member XP or levels directly:

<Tabs items={["Set XP", "Remove XP", "Set Level"]}>
  <Tab>

```text
/levels setxp member:<user> amount:<amount>
```

  </Tab>
  <Tab>

```text
/levels removexp member:<user> amount:<amount>
```

  </Tab>
  <Tab>

```text
/levels setlevel member:<user> level:<level>
```

  </Tab>
</Tabs>

## Reset

Reset all leveling data and purge saved member XP:

```text
/levels reset
```
