Greet sends a saved reply when a member sends their first message in a configured channel.

Unlike welcome messages which send immediately when someone joins the guild, Greet waits until the member actually participates in chat.

## Set up a greet message

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/welcome greet add channel:<channel> message:<text or embed> [pingable:<on or off>] [self_destruct:<seconds>]
```

  </Tab>
  <Tab>

```text
/welcome greet add channel:#general message:Welcome to {guild.name}, {user.mention}! Grab roles in #roles. self_destruct:60
```

  </Tab>
</Tabs>

## Update message content

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/welcome greet message message:<text or embed>
```

  </Tab>
  <Tab>

```text
/welcome greet message message:Hey {user.mention}, check out #roles for roles!
```

  </Tab>
</Tabs>

## View configuration

```text
/welcome greet config [channel:<channel>]
```

## Mentions & auto-delete

<Tabs items={["Pingable toggle", "Self-destruct timer"]}>
  <Tab>

```text
/welcome greet pingable state:<on or off> [channel:<channel>]
```

  </Tab>
  <Tab>

```text
/welcome greet selfdestruct delay:<seconds> [channel:<channel>]
```

  </Tab>
</Tabs>

## Test a greeting

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/welcome greet test [channel:<channel>] [member:<user>]
```

  </Tab>
  <Tab>

```text
/welcome greet test channel:#general member:@member
```

  </Tab>
</Tabs>

## Tracking history & reset

<Tabs items={["Reset member", "Clear history", "Remove greet", "Reset all"]}>
  <Tab>

```text
/welcome greet resetuser member:@member
```

Clears a member from greet tracking so they receive another greeting on their next message.

  </Tab>
  <Tab>

```text
/server greet clearhistory
```

  </Tab>
  <Tab>

```text
/welcome greet remove [channel:<channel>]
```

  </Tab>
  <Tab>

```text
/welcome greet reset
```

  </Tab>
</Tabs>
