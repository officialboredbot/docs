Reaction Triggers let bored react automatically with custom or Unicode emojis whenever a message contains a designated trigger word.

Triggers match anywhere within message content, so a saved trigger like `sob` reacts whenever that word appears.

## Add a reaction trigger

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/reaction add emoji:<emoji> trigger:<trigger word>
```

  </Tab>
  <Tab>

```text
/reaction add emoji:😭 trigger:sob
```

  </Tab>
</Tabs>

## Remove a reaction trigger

<Tabs items={["Delete emoji from trigger", "Delete all emojis for trigger"]}>
  <Tab>

```text
/reaction delete emoji:😭 trigger:sob
```

  </Tab>
  <Tab>

```text
/reaction deleteall trigger:sob
```

  </Tab>
</Tabs>

## View & inspect triggers

<Tabs items={["List triggers", "View creator"]}>
  <Tab>

```text
/reaction list
```

  </Tab>
  <Tab>

```text
/reaction owner trigger:sob
```

  </Tab>
</Tabs>

## Reset all triggers

Clear all saved reaction triggers from the server:

```text
/reaction reset
```

## Channel auto-reactions

Automatically react to every message sent in a specific media or showcase channel:

<Tabs items={["Set reactions", "List channels", "Remove reactions"]}>
  <Tab>

```text
/reaction messages channel:#selfies first:🔥 second:❤️ third:✨
```

Channels must have slowmode enabled (at least 1 minute) or be configured as an image-only channel.

  </Tab>
  <Tab>

```text
/reaction messages list
```

  </Tab>
  <Tab>

```text
/reaction messages channel:#selfies
```

  </Tab>
</Tabs>
