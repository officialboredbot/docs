Honeypot creates a visible channel that should not be used for normal chat. When a non-bot member sends a message there, bored deletes the message, increments the caught counter, refreshes the notice, and applies the configured punishment without warning the member.

The default punishment is `softban`. All honeypot commands require **Manage Server**.

## Start here

```text
/honeypot setup
```

This creates `#honeypot`, posts a warning notice with an interactive `Caught: N` indicator, and enables detection. Bot and webhook messages are ignored.

## Alerts

Configure where honeypot triggers and breach notifications are dispatched.

<Tabs items={["Syntax", "Example", "Clear"]}>
  <Tab>

```text
/honeypot alerts [channel:<channel>]
```

  </Tab>
  <Tab>

```text
/honeypot alerts channel:#mod-logs
```

  </Tab>
  <Tab>

```text
/honeypot alerts
```

  </Tab>
</Tabs>

Alerts include the member, trigger channel, applied punishment, message content, and attachment summary.

## Punishment

Configure the automated punishment applied when an account trips the trap.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/honeypot punishment punishments:<actions>
```

  </Tab>
  <Tab>

```text
/honeypot punishment punishments:timeout softban
```

  </Tab>
</Tabs>

Supported punishments are `kick`, `ban`, `softban`, and `timeout`. You can combine `timeout` with one removal punishment.

## Custom notice message

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/honeypot message message:<script>
```

  </Tab>
  <Tab>

```text
/honeypot message message:{embed}$v{title: Trap Channel}$v{description: This channel is a trap for compromised accounts. Sending any message here results in {honeypot.punishment}!}$v{footer: Accounts Caught: {honeypot.caught}}
```

  </Tab>
</Tabs>

Customize the warning notice shown in `#honeypot`. Messages support plain text, bored's embed script format, or [Components V2 container scripts](/scripting/components).

Whenever an account triggers the honeypot, the notice message automatically refreshes with the updated `{honeypot.caught}` count.

<Tabs items={["View notice", "Reset notice"]}>
  <Tab>

```text
/honeypot message view
```

Preview the active notice message or default layout.

  </Tab>
  <Tab>

```text
/honeypot message reset
```

Reset the notice message back to the default layout.

  </Tab>
</Tabs>

## View settings

```text
/honeypot settings
```

This shows whether Honeypot is enabled, the trap channel, the alert channel, the punishment list, the notice status, and the current caught count.

## Disable

```text
/honeypot disable
```

This requests confirmation, deletes the configured honeypot channel when bored can manage it, and clears the saved honeypot config.

<Callout type="warn" title="Punishment limits">
Honeypot does not punish the server owner or members above bored's highest role. Those triggers can still be reported to the alert channel.
</Callout>
