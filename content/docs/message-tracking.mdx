Message Tracking records member message totals once enabled. It powers individual stats, server activity leaderboards, and automated milestone award roles.

Bot and webhook messages are automatically ignored. Channels, categories, and roles can also be explicitly excluded from tracking.

## Enable tracking

<Tabs items={["Enable", "Disable"]}>
  <Tab>

```text
/messages enable
```

  </Tab>
  <Tab>

```text
/messages disable
```

  </Tab>
</Tabs>

New message counts start recording immediately once enabled. Disabling tracking pauses new increments without clearing recorded totals.

## View statistics

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/messages view [member:<user>]
```

  </Tab>
  <Tab>

```text
/messages view member:@zorex
```

  </Tab>
</Tabs>

Displays lifetime message count, daily volume, and a rolling 7-day activity breakdown.

## Leaderboard

View the most active members ranked by message count.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/messages leaderboard [page:<integer>]
```

  </Tab>
  <Tab>

```text
/messages leaderboard page:2
```

  </Tab>
</Tabs>

## Ignored targets

Exclude spam channels, staff channels, or privileged roles from inflating message statistics.

<Tabs items={["Ignore", "List"]}>
  <Tab>

```text
/messages ignore [channel:<channel>] [role:<role>]
```

  </Tab>
  <Tab>

```text
/messages list
```

  </Tab>
</Tabs>

Running `/messages ignore` on an already ignored channel or role un-ignores it.

## Milestone award roles

Automatically reward members with specific roles when reaching message thresholds.

<Tabs items={["Add", "Remove", "View"]}>
  <Tab>

```text
/messages awards add role:<role> messages:<integer>
```

  </Tab>
  <Tab>

```text
/messages awards remove messages:<integer>
```

  </Tab>
  <Tab>

```text
/messages awards view
```

  </Tab>
</Tabs>

Run `/messages sync` after adding or editing award roles to reconcile roles across existing members.

<Tabs items={["Sync"]}>
  <Tab>

```text
/messages sync
```

  </Tab>
</Tabs>

## Manual adjustments

Staff with `Manage Server` can manually credit or debit message counts.

<Tabs items={["Add", "Remove"]}>
  <Tab>

```text
/messages add member:<user> amount:<integer>
```

  </Tab>
  <Tab>

```text
/messages remove member:<user> amount:<integer>
```

  </Tab>
</Tabs>

Modifying balances triggers an automatic check for matching award roles.

## Sticky messages

Pin dynamic repeating messages at the bottom of busy channels.

<Tabs items={["Add", "View", "List", "Remove"]}>
  <Tab>

```text
/messages stickymessage add channel:<channel> message:<string> [pingable:<string>] [ignore_bots:<string>]
```

  </Tab>
  <Tab>

```text
/messages stickymessage view channel:<channel>
```

  </Tab>
  <Tab>

```text
/messages stickymessage list
```

  </Tab>
  <Tab>

```text
/messages stickymessage remove channel:<channel>
```

  </Tab>
</Tabs>

## Reset tracking

Wipe all tracked message data and revoke awarded roles server-wide.

```text
/messages reset
```
