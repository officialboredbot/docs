Pagination allows members to navigate multi-page embed guides and menus on a single message using reaction arrows. Navigation wraps in both directions: stepping backwards from page 1 opens the final page, and moving forwards from the last page loops back to page 1.

You need **Manage Messages** to configure pagination. bored needs permissions to add and manage reactions in the target channel.

## Set up pagination

<Steps>
  <Step title="Send the base embed">
    Create the embed that will serve as page 1 using `/createembed`, a welcome message, or another bored command.
  </Step>
  <Step title="Enable pagination">
    Copy the message link and initialize pagination on it.

    <Tabs items={["Syntax", "Example"]}>
      <Tab>

```text
/pagination set message:<message_link>
```

      </Tab>
      <Tab>

```text
/pagination set message:https://discord.com/channels/123456789012345678/234567890123456789/345678901234567890
```

      </Tab>
    </Tabs>

    bored registers the current message content as page 1 and attaches navigation reactions.
  </Step>
  <Step title="Add pages">
    Append additional embed script or Discord JSON payloads.

    <Tabs items={["Syntax", "Example"]}>
      <Tab>

```text
/pagination add message:<message_link> code:<embed_script>
```

      </Tab>
      <Tab>

```text
/pagination add message:https://discord.com/channels/123456789012345678/234567890123456789/345678901234567890 code:{embed}$v{title: Page 2}$v{description: Use the arrows to browse sections.}
```

      </Tab>
    </Tabs>

    Repeat for any number of subsequent pages.
  </Step>
</Steps>

## Page variables

Dynamic pagination variables update automatically whenever a user turns a page:

| Variable | Value |
| --- | --- |
| `{page.current}` | Current page number being displayed. |
| `{page.total}` | Total number of saved pages in the collection. |

```text
{embed}$v{title: Server Rules}$v{description: Page {page.current} of {page.total}}
```

All standard [Scripting Variables](/scripting/variables) are also supported.

## Restrict access

Lock page navigation controls so only a specific member or role can turn pages.

<Tabs items={["Restrict to role", "Restrict to user", "Clear restriction"]}>
  <Tab>

```text
/pagination restrict message:<message_link> target:@VIP
```

  </Tab>
  <Tab>

```text
/pagination restrict message:<message_link> target:@member
```

  </Tab>
  <Tab>

```text
/pagination restrict message:<message_link> target:clear
```

  </Tab>
</Tabs>

## Manage pages

<Tabs items={["Update page", "Remove page", "Restore reactions"]}>
  <Tab>

```text
/pagination update message:<message_link> page:<number> code:<embed_script>
```

  </Tab>
  <Tab>

```text
/pagination remove message:<message_link> page:<number>
```

  </Tab>
  <Tab>

```text
/pagination restorereactions message:<message_link>
```

  </Tab>
</Tabs>
