AutoPFP automates regular aesthetic image, GIF, and header drops directly from curated Pinterest collections into dedicated server channels. It also provides on-demand generation for immediate avatars and banners.

Scheduled cycles execute every 5 minutes and post batches of up to 10 images into designated channels using webhook pipelines when permitted.

## Supported collections

Available categories include:
- `females`
- `female gifs`
- `males`
- `male gifs`
- `banners`
- `banner gifs`

## Setup drops

Configure an automated drop pipeline to target a specific text channel.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/autopfp setup collection:<string> channel:<channel>
```

  </Tab>
  <Tab>

```text
/autopfp setup collection:"female gifs" channel:#pfps
```

  </Tab>
</Tabs>

Requires `Manage Server`. The bot needs permissions to send messages, embed links, attach files, and optionally manage webhooks.
