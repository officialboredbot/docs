Starboard lets bored repost popular messages into a dedicated channel once they collect enough configured reactions.

By default, the threshold starts at `3`, the default emoji is `⭐`, `selfstar` is off, and jump URL, timestamp, and attachments are on.

## Start here

<Steps>
  <Step title="Set the Starboard channel">
    Choose where reposted messages should go.

```text
/starboard set channel:#starboard
```
  </Step>
  <Step title="Confirm at least one emoji">
    New servers start with `⭐`. You can add custom or standard emojis anytime.

```text
/starboard emoji add emojis:⭐
```
  </Step>
  <Step title="Enable Starboard">
    Turn the system on once a channel and at least one emoji are ready.

```text
/starboard enable
```
  </Step>
</Steps>

Other setup commands still work while Starboard is disabled, so you can configure first and enable last.

## View the current config

```text
/starboard config
```

## Threshold

Set the number of unique reactions required before bored reposts a message.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/starboard threshold amount:<integer>
```

  </Tab>
  <Tab>

```text
/starboard threshold amount:3
```

  </Tab>
</Tabs>

The threshold must be at least `1`. The reaction count reflects unique users across all configured Starboard emojis. If the same member reacts with two watched emojis, they still count once.

## Public-only sources

Control whether restricted channels and private threads are eligible for starboard.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/starboard publiconly setting:<on or off>
```

  </Tab>
  <Tab>

```text
/starboard publiconly setting:on
```

  </Tab>
</Tabs>

When `publiconly` is on, bored only reposts messages from channels visible to `@everyone` (and the server base role, if configured). Messages from private channels or private threads are skipped.

## Self star

Control whether message authors can star their own messages.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/starboard selfstar setting:<on or off>
```

  </Tab>
  <Tab>

```text
/starboard selfstar setting:off
```

  </Tab>
</Tabs>

## Ignore targets

Ignore targets prevent starboard from tracking reactions from specific members, roles, channels, or threads.

### List ignored targets

```text
/starboard ignore list
```

## Turn Starboard off

Disable new starboard reposts without wiping your saved settings.

```text
/starboard disable
```

## Reset everything

Clear all starboard settings, ignore lists, and saved repost records for the server.

```text
/starboard reset
```
