Giveaways post a giveaway embed, collect entries via reactions, verify eligibility automatically when the timer expires, and announce the selected winners.

Staff members need `Manage Channels` to manage giveaways. Awarding winner roles requires the bot and runner to have `Manage Roles`.

## Start a giveaway

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/giveaway start duration:<string> winners:<integer> prize:<string> [channel:<channel>] [description:<string>] [hosts:<string>] [requiredroles:<string>] [roles:<string>] [voice:<string>] [minlevel:<integer>] [maxlevel:<integer>] [invites:<integer>] [messages:<integer>] [voicelevel:<integer>] [age:<integer>] [stay:<integer>] [color:<string>] [thumbnail:<string>] [image:<string>] [bonus_target:<mentionable>] [bonus_entries:<integer>]
```

  </Tab>
  <Tab>

```text
/giveaway start duration:24h winners:2 prize:Discord Nitro channel:#giveaways requiredroles:@Member bonus_target:@Booster bonus_entries:2
```

  </Tab>
</Tabs>

If you omit `channel`, bored uses the configured default giveaway channel. If no default is configured, it sends to the channel where the command was invoked.

## Giveaway parameters

<Accordions>
  <Accordion title="Description">
    Adds additional copy above the giveaway status block. Plain text and bored embed scripting are supported.

```text
description:<text>
```
  </Accordion>
  <Accordion title="Hosts">
    Sets visible hosts in the giveaway embed instead of only the command runner.

```text
hosts:<@members>
```
  </Accordion>
  <Accordion title="Required roles">
    Requires entrants to possess at least one of the listed roles.

```text
requiredroles:<@roles>
```
  </Accordion>
  <Accordion title="Winner roles">
    Automatically awards the listed roles to winners upon completion. Requires `Manage Roles`.

```text
roles:<@roles>
```
  </Accordion>
  <Accordion title="Bonus entries">
    Grants a specific role or member extra entries (up to 100 bonus entries).

```text
bonus_target:<@role|@member> bonus_entries:<count>
```
  </Accordion>
  <Accordion title="Voice requirement">
    Requires entrants to be actively connected to a voice channel.

```text
voice:on
```
  </Accordion>
  <Accordion title="Chat levels">
    Requires bored's message leveling data. Set `minlevel` and `maxlevel` to constrain entry to a specific level window.

```text
minlevel:<level> maxlevel:<level>
```
  </Accordion>
  <Accordion title="Invites and messages">
    Requires invite tracking or message tracking activity thresholds before entry is valid.

```text
invites:<count> messages:<count>
```
  </Accordion>
  <Accordion title="Voice level">
    Requires bored's voice leveling data to meet or exceed a specific voice level.

```text
voicelevel:<level>
```
  </Accordion>
  <Accordion title="Account age and server stay">
    Requires a minimum Discord account age or minimum time in this server (specified in days).

```text
age:<days> stay:<days>
```
  </Accordion>
  <Accordion title="Appearance and media">
    Sets a custom embed color, thumbnail, or main banner image via URL or direct attachment upload.

```text
color:<hex> thumbnail:<url> image:<url>
```
  </Accordion>
</Accordions>

## Default channel

<Tabs items={["Set", "Clear"]}>
  <Tab>

```text
/giveaway channel channel:<channel>
```

  </Tab>
  <Tab>

```text
/giveaway channel
```

  </Tab>
</Tabs>

Omit the `channel` parameter to clear the default giveaway channel.

## Manage giveaways

<Tabs items={["End", "Cancel", "Reroll"]}>
  <Tab>

```text
/giveaway end message_id:<id>
```

  </Tab>
  <Tab>

```text
/giveaway cancel message_id:<id>
```

  </Tab>
  <Tab>

```text
/giveaway reroll message_id:<id> [winners:<count>]
```

  </Tab>
</Tabs>

## Edit a giveaway

Modify properties of an active giveaway message without restarting it.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/giveaway edit message_id:<id> [prize:<string>] [duration:<string>] [winners:<integer>] [description:<string>] [hosts:<string>] [requiredroles:<string>] [roles:<string>] [voice:<string>] [minlevel:<integer>] [maxlevel:<integer>] [invites:<integer>] [messages:<integer>] [bonus_target:<mentionable>] [bonus_entries:<integer>]
```

  </Tab>
  <Tab>

```text
/giveaway edit message_id:123456789012345678 prize:$50 Steam Card winners:3
```

  </Tab>
</Tabs>

## Blacklists

Restrict specific members or roles from entering giveaways across the server.

<Tabs items={["Toggle", "List"]}>
  <Tab>

```text
/giveaway blacklist target:<member|role>
```

  </Tab>
  <Tab>

```text
/giveaway blacklists
```

  </Tab>
</Tabs>

Running `/giveaway blacklist` on an already blacklisted member or role will unblacklist them.

## Overview and cleanup

<Tabs items={["List", "Clear"]}>
  <Tab>

```text
/giveaway list
```

  </Tab>
  <Tab>

```text
/giveaway clear
```

  </Tab>
</Tabs>

`/giveaway clear` removes ended or cancelled giveaways from the stored registry.
