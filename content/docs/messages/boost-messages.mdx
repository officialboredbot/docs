Boost Messages automatically dispatch celebratory thank-you announcements when members boost your Discord server.

## Add a boost message

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/settings boosts add channel:<channel> message:<text or embed script>
```

  </Tab>
  <Tab>

```text
/settings boosts add channel:#boosts message:Thank you for boosting {guild.name}, {user.mention}! ✨
```

  </Tab>
</Tabs>

## View & test boost messages

<Tabs items={["View message", "Test live in channel", "List channels"]}>
  <Tab>

```text
/settings boosts view channel:#boosts
```

  </Tab>
  <Tab>

```text
/settings boosts test channel:#boosts
```

  </Tab>
  <Tab>

```text
/settings boosts list
```

  </Tab>
</Tabs>

## Remove a boost message

```text
/settings boosts remove channel:#boosts
```
