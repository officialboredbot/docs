Welcome Messages dispatch customized greeting messages, rich embeds, or interactive cards whenever a new member joins your server.

<Callout type="warning" title="Raid state">
When AntiRaid **raid state** is active, welcome messages are temporarily paused until the raid batch is cleared.
</Callout>

## Add a welcome message

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/welcome add channel:<channel> message:<text or embed script>
```

  </Tab>
  <Tab>

```text
/welcome add channel:#welcome message:Welcome to {guild.name}, {user.mention}!
```

  </Tab>
</Tabs>

Messages support plain text, bored's embed scripting format (`{embed}$v...`), and [Components V2 container scripts](/scripting/components).

<Callout type="info" title="Invite-aware welcomes">
If [Invite Tracking](/invite-tracking) is enabled and your welcome message uses invite variables like `{inviter}` or `{invite.code}`, it seamlessly replaces the default tracker notice.
</Callout>
