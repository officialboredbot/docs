import { Tabs, Tab } from "fumadocs-ui/components/tabs";

Leave Messages dispatch custom departure notices when members leave or are kicked from your server.

<Callout type="warning" title="Raid state">
When AntiRaid **raid state** is active, leave messages are temporarily paused.
</Callout>

## Add a leave message

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/leave add channel:<channel> message:<text or embed script>
```

  </Tab>
  <Tab>

```text
/leave add channel:#goodbye message:Goodbye {user.name}, we'll miss you!
```

  </Tab>
</Tabs>

## View & test leave messages

<Tabs items={["View saved message", "Test live in channel", "List channels"]}>
  <Tab>

```text
/leave view channel:#goodbye
```

  </Tab>
  <Tab>

```text
/leave test channel:#goodbye
```

  </Tab>
  <Tab>

```text

```

  </Tab>
</Tabs>

## Remove or reset

<Tabs items={["Remove single", "Reset all"]}>
  <Tab>

```text
/leave remove channel:#goodbye
```

  </Tab>
  <Tab>

```text
/leave reset
```

  </Tab>
