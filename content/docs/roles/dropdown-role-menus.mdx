Dropdown Role Menus attach persistent select dropdowns to messages sent by bored. Members can pick multiple interests, notification pings, or choose one option from an exclusive set.

<Callout type="warning" title="Bot messages only">
Role menus can only be attached to messages sent by **bored** (such as custom embed posts).
</Callout>

## Modes

* **Multiple (`multiple`)**: Members can toggle multiple roles simultaneously. Selecting an assigned role unassigns it.
* **Exclusive (`exclusive`)**: Members can only hold one role from the menu at a time. Selecting a new option strips the previous one.

## Create a menu

Creating a menu attaches the first role and initializes the dropdown component on the target message.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/autorole rolemenu create message_link:<URL> role:<role> [mode:<multiple or exclusive>] [placeholder:<placeholder text>] [label:<label>] [description:<description>] [emoji:<emoji>]
```

  </Tab>
  <Tab>

```text
/autorole rolemenu create message_link:https://discord.com/channels/1/2/3 role:@Announcements mode:multiple placeholder:Choose your notification roles
```

  </Tab>
</Tabs>

## Add options to an existing menu

Add additional role choices to an already initialized dropdown:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/autorole rolemenu add message_link:<URL> menu:<menu index> role:<role> [label:<label>] [description:<description>] [emoji:<emoji>]
```

  </Tab>
  <Tab>

```text
/autorole rolemenu add message_link:https://discord.com/channels/1/2/3 menu:1 role:@Events label:Event Alerts description:Get pinged for server giveaways & events emoji:🎉
```

  </Tab>
</Tabs>

## Edit menu settings

Modify placeholder text, toggle between exclusive/multiple mode, or change max allowed selections:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/autorole rolemenu edit message_link:<URL> menu:<menu index> [mode:<mode>] [max_values:<1-25>] [placeholder:<text>]
```

  </Tab>
  <Tab>

```text
/autorole rolemenu edit message_link:https://discord.com/channels/1/2/3 menu:1 placeholder:Select up to 3 roles max_values:3
```

  </Tab>
</Tabs>

## View & inspect menus

Inspect the menu hierarchy, option indexes, and active configurations on a message:

```text
/autorole rolemenu view message_link:https://discord.com/channels/1/2/3
```

## Remove options & delete menus

<Tabs items={["Remove single option", "Delete entire menu", "Clear message"]}>
  <Tab>

```text
/autorole rolemenu remove message_link:https://discord.com/channels/1/2/3 menu:1 role_position:2
```

Removes the 2nd role option from menu #1.

  </Tab>
  <Tab>

```text
/autorole rolemenu delete message_link:https://discord.com/channels/1/2/3 menu:1
```

Deletes dropdown row #1 completely.

  </Tab>
  <Tab>

```text
/autorole rolemenu clear message_link:https://discord.com/channels/1/2/3
```

Removes all dropdowns attached to the message.

  </Tab>
</Tabs>

## View all menus & reset

<Tabs items={["List all menus", "Reset server"]}>
  <Tab>

```text
/autorole rolemenu list
```

  </Tab>
  <Tab>

```text
/autorole rolemenu reset
```

  </Tab>
</Tabs>
