Reaction Roles let members assign or remove roles simply by reacting to a designated message with a saved emoji.

## Add a reaction role

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/autorole reactionrole add message_link:<URL> reaction:<emoji> role:<role> [exclusive:<true or false>]
```

  </Tab>
  <Tab>

```text
/autorole reactionrole add message_link:https://discord.com/channels/1/2/3 reaction:✅ role:@Verified
```

  </Tab>
</Tabs>

bored automatically adds the initial reaction to the message once configured.

### Exclusive reaction roles

Set `exclusive:true` when members should only hold one role from that reaction group at a time:

```text
/autorole reactionrole add message_link:https://discord.com/channels/1/2/3 reaction:🔞 role:@18+ exclusive:true
/autorole reactionrole add message_link:https://discord.com/channels/1/2/3 reaction:🚫 role:@18- exclusive:true
```

When a member reacts with `🚫`, bored removes `@18+`, awards `@18-`, and purges their previous reaction.

## Remove reaction roles

<Tabs items={["Remove single reaction", "Remove all reactions from message"]}>
  <Tab>

```text
/autorole reactionrole remove message_link:https://discord.com/channels/1/2/3 reaction:✅
```

  </Tab>
  <Tab>

```text
/autorole reactionrole removeall message_link:https://discord.com/channels/1/2/3
```

  </Tab>
</Tabs>

## View active reaction roles

```text
/autorole reactionrole list
```

## Reset all reaction roles

Clear all reaction role bindings across the server:

```text
/autorole reactionrole reset
```
