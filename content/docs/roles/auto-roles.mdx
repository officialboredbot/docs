Auto Roles automatically assigns roles to new joins. You can configure roles for all members, roles strictly for human users, or roles strictly for bots.

bored's highest role must be positioned above the roles you assign.

## Everyone (Humans & Bots)

<Tabs items={["Add", "Remove", "List", "Reset"]}>
  <Tab>

```text
/autorole add role:<role>
```

  </Tab>
  <Tab>

```text
/autorole remove role:<role>
```

  </Tab>
  <Tab>

```text
/autorole list
```

  </Tab>
  <Tab>

```text
/autorole reset
```

  </Tab>
</Tabs>

## Human members only

Assign roles exclusively to non-bot members upon joining:

<Tabs items={["Add", "Remove", "List", "Reset"]}>
  <Tab>

```text
/autorole humans add role:<role>
```

Example: `/autorole humans add role:@Member`

  </Tab>
  <Tab>

```text
/autorole humans remove role:<role>
```

  </Tab>
  <Tab>

```text
/autorole humans list
```

  </Tab>
  <Tab>

```text
/autorole humans reset
```

  </Tab>
</Tabs>
