Guild tag roles award designated roles when a member equips your server's custom Discord **guild tag** badge on their profile.

<Callout type="warning" title="Server requirement">
Your server must have Discord guild tags unlocked.
</Callout>

## Quickstart

<Steps>
  <Step title="Add reward roles">
    Add the roles members should receive when sporting your server tag:

```text
/server badge role action:add role:@Tagged
```
  </Step>
  <Step title="Configure announcement channel">
    Set where public celebratory messages are posted:

```text
/server badge channel channel:#tag-rewards
```
  </Step>
  <Step title="Sync existing members">
    Backfill rewards for members who already have your server tag equipped:

```text
/server badge sync
```
  </Step>
</Steps>
