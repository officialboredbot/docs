Vanity Roles are managed by the dedicated companion [**bored vanity**](https://discord.com/oauth2/authorize?client_id=1459869503289561293) bot. It automatically awards roles when a member includes your server's custom vanity invite code in their Discord Custom Status.

<Callout type="warning" title="Server requirement">
Your server must have a custom **vanity URL** (Discord Level 3 Server Boost).
</Callout>

<Callout type="warning" title="Companion bot architecture">
**bored vanity** joins servers that already have the main **bored** bot. The bot is permanently whitelisted from AntiNuke.
</Callout>

## Set vanity string

Configure the custom status substring bored-vanity searches for:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/vanity string action:set text:<vanity substring>
```

  </Tab>
  <Tab>

```text
/vanity string action:set text:.gg/boredbot
```

  </Tab>
</Tabs>

## Manage reward roles

<Tabs items={["Add role", "Remove role", "List roles"]}>
  <Tab>

```text
/vanity role action:add role:@Vanity
```

  </Tab>
  <Tab>

```text
/vanity role action:remove role:@Vanity
```

  </Tab>
  <Tab>

```text
/vanity role action:list
```

  </Tab>
</Tabs>

## Offline member status handling

Control whether members retain their vanity role when offline or invisible:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/vanity offline setting:<yes or no>
```

  </Tab>
  <Tab>

```text
/vanity offline setting:no
```

  </Tab>
</Tabs>

`/vanity offline setting:no` is the recommended default. It preserves roles during client disconnects and network reconnects, preventing role flapping and duplicate award DMs.

## Award notifications & channel

<Tabs items={["Set channel", "Set message", "Sync members"]}>
  <Tab>

```text
/vanity channel channel:#vanity-rewards
```

  </Tab>
  <Tab>

```text
/vanity message action:set text:Thanks for repping our vanity, {user.mention}!
```

  </Tab>
  <Tab>

```text
/vanity sync
```

Backfills and syncs vanity roles across all online members.

  </Tab>
</Tabs>
