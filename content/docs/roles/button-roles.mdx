Button Roles let members assign or remove roles by clicking interactive buttons attached to a bot message.

bored's highest role must be positioned above any roles configured for button roles.

## Add a button role

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/autorole buttonrole add message_link:<URL> role:<role> [label:<text>] [style:<color>] [emoji:<emoji>] [exclusive:<true or false>]
```

  </Tab>
  <Tab>

```text
/autorole buttonrole add message_link:https://discord.com/channels/1/2/3 role:@Verified style:green emoji:✅ label:Verify Here
```

  </Tab>
</Tabs>

### Button styles

* `green` (Success)
* `blurple` (Primary)
* `gray` (Secondary)
* `red` (Danger)

### Exclusive button sets

Set `exclusive:true` when members should only hold one role at a time from that button group (e.g. mutually exclusive notification or age roles). Clicking an alternate option strips the previous role and grants the new one.

<Callout type="warning" title="Target messages">
Button roles can only be attached to messages sent by **bored** (such as custom embed posts or embed script messages), as Discord requires the message author to edit components.
</Callout>

## Remove button roles

<Tabs items={["Remove single button", "Remove all buttons from message"]}>
  <Tab>

```text
/autorole buttonrole remove message_link:https://discord.com/channels/1/2/3 index:1
```

Index represents button position from left to right starting at `1`.

  </Tab>
  <Tab>

```text
/autorole buttonrole removeall message_link:https://discord.com/channels/1/2/3
```

  </Tab>
</Tabs>

## View active button roles

```text
/autorole buttonrole list
```

## Reset all button roles

Wipes every button role configured across the server:

```text
/autorole buttonrole reset
```
