Booster Roles let server boosters create, color, and manage their own personalized custom roles. Staff can set position anchors, filters, share allowances, and manual booster overrides.

## Create a booster role

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/boosterrole create name:<role name> [color:<hex or color name>] [second_color:<gradient hex>]
```

  </Tab>
  <Tab>

```text
/boosterrole create name:VIP color:#ffcc00
```

  </Tab>
</Tabs>

If you specify two colors on supported servers, bored renders a smooth role color gradient.

## Customization

<Tabs items={["Color", "Icon", "Rename", "Dominant", "Random", "Delete"]}>
  <Tab>

```text
/boosterrole color color:<hex> [second_color:<hex>] [name:<color name>]
```

  </Tab>
  <Tab>

```text
/boosterrole icon [url:<image URL>] [emoji:<emoji>] [attachment:<file>]
```

  </Tab>
  <Tab>

```text
/boosterrole rename new_name:<new name>
```

  </Tab>
  <Tab>

```text
/boosterrole dominant
```

Extracts and applies the dominant color from your Discord avatar.

  </Tab>
  <Tab>

```text
/boosterrole random
```

  </Tab>
  <Tab>

```text
/boosterrole remove
```

  </Tab>
</Tabs>

## Staff configuration

### Hierarchy anchor & award role

<Tabs items={["Base role position", "Booster limit", "Award role"]}>
  <Tab>

```text
/boosterrole base role:<role>
```

Positions new booster roles directly above this anchor role in the server hierarchy.

  </Tab>
  <Tab>

```text
/boosterrole limit limit:1
```

  </Tab>
  <Tab>

```text
/boosterrole award set role:@Server Booster
```

  </Tab>
</Tabs>

### Booster role override

Allow specific members to keep and manage a booster role even if they are not actively boosting the server (e.g. server staff, contest winners, or lifetime VIPs):

<Tabs items={["Add override", "Remove override", "List overrides", "Reset"]}>
  <Tab>

```text
/boosterrole override add member:@VIP-User
```

  </Tab>
  <Tab>

```text
/boosterrole override remove member:@VIP-User
```

  </Tab>
  <Tab>

```text
/boosterrole override list
```

  </Tab>
  <Tab>

```text
/boosterrole override reset
```

  </Tab>
</Tabs>

## Role sharing & filters

<Tabs items={["Share with friend", "Filter name words", "Cleanup"]}>
  <Tab>

```text
/boosterrole share add member:@friend
```

Shares your booster role with another member. Staff can configure caps with `/boosterrole share max limit:3`.

  </Tab>
  <Tab>

```text
/boosterrole filter toggle word:<forbidden word>
```

Blocks inappropriate words from being used in booster role names.

  </Tab>
  <Tab>

```text
/boosterrole cleanup
```

Prunes orphaned booster roles whose owners left or stopped boosting.

  </Tab>
</Tabs>
