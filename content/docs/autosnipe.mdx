Autosnipe streams snipe events automatically to designated channels rather than requiring manual invocations of `/snipe`, `/editsnipe`, or `/reaction reactionsnipe`.

Each event type can post to **one channel per server**. Enabling an event type in a new channel replaces the previous destination. Autosnipe respects `/filter snipe` exclusions.

## Enable an event type

Configure automatic snipe forwarding for specific message lifecycle events.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/autosnipe channel event:<delete|edit|reaction> channel:<channel> [state:<on|off>]
```

  </Tab>
  <Tab>

```text
/autosnipe channel event:delete channel:#logs state:on
```

  </Tab>
</Tabs>

## Enable all events

Send deleted messages, edited messages, and removed reactions to a unified log channel.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/autosnipe all channel:<channel> [state:<on|off>]
```

  </Tab>
  <Tab>

```text
/autosnipe all channel:#logs state:on
```

  </Tab>
</Tabs>

## View configuration

Inspect currently active autosnipe channels across all event types.

<Tabs items={["Config", "List"]}>
  <Tab>

```text
/autosnipe config
```

  </Tab>
  <Tab>

```text
/autosnipe list
```

  </Tab>
</Tabs>

## Manual snipe commands

For on-demand inspection, use the native slash snipe suite:

<Tabs items={["Deleted", "Edited", "Reactions", "Clear"]}>
  <Tab>

```text
/snipe [index:<integer>]
```

  </Tab>
  <Tab>

```text
/editsnipe [index:<integer>]
```

  </Tab>
  <Tab>

```text
/reaction reactionsnipe [index:<integer>]
```

  </Tab>
  <Tab>

```text
/clearsnipe
```

  </Tab>
</Tabs>

## Reset autosnipe

Disable autosnipe for a specific channel or clear server-wide settings.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/autosnipe reset [channel:<channel>]
```

  </Tab>
  <Tab>

```text
/autosnipe reset channel:#logs
```

  </Tab>
</Tabs>
