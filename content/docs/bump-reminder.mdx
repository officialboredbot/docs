Bump Reminder monitors a channel for successful DISBOARD `/bump` executions, posts an automated thank-you note, and schedules a reminder alert `2` hours later when bumping is ready again.

## Set bump channel

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/bumpreminder channel channel:<channel>
```

  </Tab>
  <Tab>

```text
/bumpreminder channel channel:#bump
```

  </Tab>
</Tabs>

## Reminder message

Configure the reminder message posted 2 hours after a bump:

<Tabs items={["Set message", "Preview"]}>
  <Tab>

```text
/bumpreminder message set [message:<text or embed>] [pingable:<on or off>] [remind_once:<on or off>]
```

Example: `/bumpreminder message set message:{bumpreminder.last_user}, time to /bump! pingable:on`

  </Tab>
  <Tab>

```text
/bumpreminder message view
```

  </Tab>
</Tabs>

## Thank-you message

Configure the immediate acknowledgement sent when a member bumps:

<Tabs items={["Set thank-you", "Preview"]}>
  <Tab>

```text
/bumpreminder thankyou set [message:<text or embed>] [pingable:<on or off>]
```

Example: `/bumpreminder thankyou set message:Thanks for bumping the server, {bumpreminder.last_user}!`

  </Tab>
  <Tab>

```text
/bumpreminder thankyou view
```

  </Tab>
</Tabs>

## Channel automation

<Tabs items={["Auto-lock", "Auto-clean"]}>
  <Tab>

```text
/bumpreminder autolock choice:<on or off>
```

Locks `#bump` for `@everyone` after a successful bump, and automatically unlocks it 2 hours later when the reminder fires.

  </Tab>
  <Tab>

```text
/bumpreminder autoclean choice:<on or off>
```

Automatically purges non-bump chat from the bump channel.

  </Tab>
</Tabs>

## Dynamic variables

* `{bumpreminder.last_user}` — Mention of the member who ran the last bump.
* `{bumpreminder.next_bump}` — Relative Discord timestamp until the next eligible bump.

## View settings & disable

</Tabs>
