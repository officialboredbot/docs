Use customization to change how bored appears inside your server with a server-specific avatar, banner, bio, and nickname.

<Callout type="warning" title="Access and cooldowns">
Customization is available to the **server owner** and **antinuke admins**. Avatar, banner, bio, and reset each have a **6 hour** cooldown. `/customize name` has a **5 minute** cooldown.
</Callout>

## Update avatar

Set bored's server avatar for the current server using an image URL or direct file upload.

<Tabs items={["Syntax", "Example", "Upload"]}>
  <Tab>

```text
/customize avatar [url:<image URL>] [attachment:<file>]
```

  </Tab>
  <Tab>

```text
/customize avatar url:https://cdn.example.com/avatar.png
```

  </Tab>
  <Tab>

```text
/customize avatar attachment:<uploaded image>
```

  </Tab>
</Tabs>

## Update banner

Set bored's server banner for the current server using a banner image URL or file upload.

<Tabs items={["Syntax", "Example", "Upload"]}>
  <Tab>

```text
/customize banner [url:<image URL>] [attachment:<file>]
```

  </Tab>
  <Tab>

```text
/customize banner url:https://cdn.example.com/banner.png
```

  </Tab>
  <Tab>

```text
/customize banner attachment:<uploaded image>
```

  </Tab>
</Tabs>

## Update bio

Set bored's server bio text. The final bio must stay within `190` characters after any automatic link is added. If the bio does not already include `bored.rest` or `discord.gg/boredbot`, bored appends `https://bored.rest` automatically.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/customize bio text:<bio text>
```

  </Tab>
  <Tab>

```text
/customize bio text:support server @ discord.gg/boredbot
```

  </Tab>
</Tabs>

## Update nickname

Set bored's nickname in the current server.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/customize name nickname:<nickname>
```

  </Tab>
  <Tab>

```text
/customize name nickname:bored
```

  </Tab>
</Tabs>

This only changes the server nickname. It uses the shorter **5 minute** cooldown.

## Reset

Reset bored's server avatar, banner, bio, and nickname back to the default profile for your server.

```text
/customize reset
```
