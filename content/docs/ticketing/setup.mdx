Use quick setup when you want a complete, working ticket panel without manual category and channel setup.

## Run quick setup

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/ticket setup
```

  </Tab>
  <Tab>

```text
/ticket setup
```

  </Tab>
</Tabs>

Quick setup prompts for:

- Support roles for the default `Support` option
- Channel where close logs and transcripts should be sent
- Channel where the public panel embed should be posted

Then bored automatically:

- Creates a `Tickets` category
- Saves server-wide ticket settings
- Creates a `Support` panel with one default option
- Posts the public panel message in the channel you chose

## Open the configurator

After quick setup — or anytime you need to customize settings — run:

```text
/ticket config
```

The interactive configurator opens with two sections:

| Section | What it covers |
| --- | --- |
| **Ticket Settings** | Server-wide defaults, transcripts, and post-close actions |
| **Manage Ticket Panels** | Panels, public embeds, option buttons, forms, and categories |

## Ticket settings

Open **Ticket Settings** to manage defaults that apply across all tickets:

- **Log channel** — where close logs and ticket actions are recorded
- **Ticket category** — fallback category when an option does not set its own
- **Ticket cooldown** — wait time before someone can open another ticket
- **Default auto-close** — fallback hours for `/ticket autoclose` when no value is given
- **Close on user leave** — automatically close a member's open tickets when they leave the server
- **Send close log to user** — DM the ticket opener a close log with the transcript link (enabled by default)
- **Auto Delete on Close** — delete a closed ticket after a delay from **1 minute** to **30 days**, or keep archived
- **Closed Ticket Category** — move closed ticket channels into a separate category
- **Closed Channel Name** — rename closed channels with a template like `closed-{ticket.number}`

<Callout type="warning" title="Image transcripts">
Keeping **Auto Delete on Close** set to **Off** and keeping the channels archived allows Discord image attachments to render permanently in transcripts.
</Callout>

## Closed ticket behavior

Closing a ticket locks the channel instead of deleting it immediately. The closed message includes **Reopen** and **Delete** buttons.

When configured, bored can move the channel into a closed category, rename it, and schedule automatic deletion.

Reopening cancels scheduled deletion, restores original permissions and controls, and removes the closed notice.
