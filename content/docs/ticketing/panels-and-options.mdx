Panels and options are the core of ticket configuration. A panel represents the shared public embed post, while options are individual buttons or dropdown choices members click to open private channels.

## Resend a panel

Members only see ticket choices on the **active** panel message. After modifying options, display mode, or embed copy, resend the panel so the public message reflects the latest configuration:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/ticket panel panel:<panel name> [channel:<channel>]
```

  </Tab>
  <Tab>

```text
/ticket panel panel:Support channel:#tickets
```

  </Tab>
</Tabs>

If you omit the channel option, bored sends the panel to its saved channel.

## Build a multi-option panel

<Steps>
  <Step title="Open the configurator">
    Run `/ticket config` and choose **Manage Ticket Panels**.
  </Step>
  <Step title="Create or select a panel">
    Select **Create Panel** or choose an existing panel from the menu.
  </Step>
  <Step title="Set the panel message">
    Configure the shared embed layout, public channel, and whether options appear as **Buttons** or a **Dropdown Menu**.
  </Step>
  <Step title="Add ticket options">
    Open **Ticket Options**, then **Add Option** for each ticket choice you want on that panel (e.g. `General Support`, `Billing`, `Staff Report`).
  </Step>
  <Step title="Configure options">
    Configure specific button styles, categories, support roles, welcome embeds, claiming rules, and form modals.
  </Step>
  <Step title="Resend the panel">
    Run `/ticket panel panel:Support channel:#tickets` to post the live controls.
  </Step>
</Steps>

## Panel configuration sections

| Section | Purpose |
| --- | --- |
| **Ticket Settings** | Panel display name and maximum open tickets per user |
| **Panel Message** | Shared embed script or Components V2 container, target channel, and button/dropdown mode |
| **Ticket Options** | List, add, enable, disable, and customize ticket choices |
| **Log Channel** | Optional channel override for where this panel's transcripts are recorded |

## Option editor

| Section | Purpose |
| --- | --- |
| **Ticket Settings** | Option name, support roles, ping support toggle, allow opener close, channel naming format |
| **Button** | Button label, emoji, and button style (green, blurple, gray, red) |
| **Category** | Destination category where channels are opened |
| **Claiming** | Allow claiming, and toggle **Claim Lock** |
| **Welcome Message** | Initial greeting embed and close/claim action buttons inside the ticket |
| **Forms** | Modal questions asked before the ticket opens |

## Forms shortcut

Jump directly to the form builder for a panel:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/ticket forms [panel:<panel name>]
```

  </Tab>
  <Tab>

```text
/ticket forms panel:Support
```

  </Tab>
</Tabs>
