This page covers slash commands executed inside ticket channels or by server administrators.

## Permission tiers

- **Support roles** assigned to a ticket option can claim, unclaim, close, add/remove members, and view ticket metadata.
- **Manage Server** (`manage_guild`) administrators have full access to admin overrides and staff tools.
- The **ticket opener** can run `/ticket closerequest` or `/ticket close` if permitted.

## Staff in-channel commands

### Claim & Unclaim

<Tabs items={["Claim", "Unclaim"]}>
  <Tab>

```text
/ticket claim
```

Assigns the ticket to you. If **Claim Lock** is enabled, only you and the opener can send messages until unclaimed.

  </Tab>
  <Tab>

```text
/ticket unclaim
```

Releases the claim, restoring normal send permissions to all support staff.

  </Tab>
</Tabs>

### Manage participant access

<Tabs items={["Add access", "Remove access"]}>
  <Tab>

```text
/ticket add target:<member or role>
```

Example: `/ticket add target:@Billing-Support`

  </Tab>
  <Tab>

```text
/ticket remove target:<member or role>
```

Example: `/ticket remove target:@Billing-Support`

  </Tab>
</Tabs>

### View ticket info

```text
/ticket info
```

Displays ticket number, creator, current claimer, category, and active countdown timers.

## Closing & lifecycle

### Close immediately

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/ticket close [reason:<reason>]
```

  </Tab>
  <Tab>

```text
/ticket close reason:Issue resolved by support
```

  </Tab>
</Tabs>

Locks the ticket channel, generates a secure online HTML transcript, and renders **Reopen** and **Delete** buttons.

### Close requests

Request confirmation from the opener before closing:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/ticket closerequest [reason:<reason>] [timeout:<duration>]
```

  </Tab>
  <Tab>

```text
/ticket closerequest reason:Has your issue been resolved? timeout:10m
```

  </Tab>
</Tabs>

If the user does not respond within the timeout, bored closes the ticket automatically.

### Automated inactivity closure

Schedule automatic closing if the channel remains idle:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/ticket autoclose [hours:<integer>]
```

  </Tab>
  <Tab>

```text
/ticket autoclose hours:24
```

  </Tab>
</Tabs>

Any new message from the user cancels pending auto-close.

### Reopen or delete

<Tabs items={["Reopen", "Delete"]}>
  <Tab>

```text
/ticket reopen [ticket_id:<id>] [reason:<reason>]
```

Restores original channel permissions, name, and controls.

  </Tab>
  <Tab>

```text
/ticket delete [ticket_id:<id>] [reason:<reason>]
```

Deletes the channel after a 3-second safety window. Transcripts remain permanently accessible via their private links.

  </Tab>
</Tabs>

### Move ticket category

```text
/ticket move category:<category>
```

## Admin overrides

### Blacklist member or role

Toggle ticket opening bans:

```text
/ticket blacklist target:@abusive-user
```

### Force open a ticket

Open a ticket on behalf of a user:

```text
/ticket force user:@member [panel:Support]
```

### Update close reason

Modify the recorded reason for an archived ticket:

```text
/ticket reason ticket_id:7 new_reason:User stopped responding
```
