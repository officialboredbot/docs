`filter` is bored's comprehensive chat protection system. It combines Discord AutoMod rules with bored's high-speed runtime checks so staff can control server-wide filters, channel-scoped filters, word rules, whitelists, and snipe safety from one unified command suite.

`filter links` and `filter invites` default to **on** across all channels.

## How it works

Filter operates across three coordinated layers:

- **AutoMod filters** use Discord AutoMod to block messages before they land. This covers `links`, `invites`, and the word/regex filter.
- **Runtime filters** are enforced directly by bored after a message is sent. This covers `spam`, `caps`, `spoilers`, `massmention`, `musicfiles`, `emoji`, and `edit`.
- **Snipe filters** do not block live chat. They decide which deleted or edited content `snipe` and `editsnipe` are allowed to show later.

  <Step title="Apply the starter preset">

## Word filter

The word filter syncs blocked phrases directly into Discord's native AutoMod keyword rule, blocking messages instantly at the API boundary.

### Add or remove keywords

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/filter add word:<keyword>
/filter remove word:<keyword>
```

  </Tab>
  <Tab>

```text
/filter add word:free nitro
/filter remove word:free nitro
```

  </Tab>
</Tabs>

### List and reset keywords

```text
/filter list
/filter reset
```

### Word whitelist

Whitelisted words are exempted from the word filter:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/filter whitelist [word:<word>] [view_list:<true or false>]
```

  </Tab>
  <Tab>

```text
/filter whitelist word:bored.rest
```

  </Tab>
</Tabs>

### Regex patterns

Sync custom regex patterns into Discord AutoMod:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/filter regex [pattern:<regex>] [view_list:<true or false>]
```

  </Tab>
  <Tab>

```text
/filter regex pattern:(?i)free\s+nitro
```

  </Tab>
</Tabs>

## Runtime filters

Runtime filters are evaluated in real time by bored. When triggered, the message is deleted, and optional timeout punishments are applied.

### Spam bursts

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text

```

  </Tab>
  <Tab>

```text
/filter spam set setting:on all_channels:true threshold:6 window:8s action:timeout timeout_duration:5m
```

## Exemptions

Exempt roles, channels, categories, or members from specific filters:

```text
/filter exempt toggle [channel:<channel>] [role:<role>] [member:<user>]
/filter exempt list
```

## Snipe safety

Prevent sensitive content (like deleted invites, links, or filtered words) from being exposed through `/snipe` or `/editsnipe`:

<Tabs items={["Syntax", "Example", "List"]}>
  <Tab>

```text
/filter snipe [kind:<invites|links|word|images|files>] [view_list:<true or false>]
```

  </Tab>
  <Tab>

```text
/filter snipe kind:invites
```

  </Tab>
  <Tab>

```text
/filter snipe view_list:true
```

  </Tab>
</Tabs>
