Timers automatically broadcast recurring messages to text channels on a scheduled interval. Messages support plain text, embed scripting, and dynamic server variables.

The minimum interval is `60` seconds.

## Add a timer

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/server timer add channel:<channel> interval:<duration> message:<text or embed>
```

  </Tab>
  <Tab>

```text
/server timer add channel:#announcements interval:6h message:Remember to check out the latest server updates and events!
```

  </Tab>
</Tabs>

Intervals accept duration formats like `30m`, `1h`, or `1d`.

## Preview or remove timers

<Tabs items={["Preview message", "Remove timer"]}>
  <Tab>

```text
/server timer view channel:#announcements
```

  </Tab>
  <Tab>

```text
/server timer remove channel:#announcements
```

  </Tab>
</Tabs>

## View active timers

```text
/server timer list
```

## Activity requirement

Prevent timer messages from spamming inactive or dead channels:

<Tabs items={["Enable activity gate", "Disable activity gate"]}>
  <Tab>

```text
/server timer activity setting:on
```

  </Tab>
  <Tab>

```text
/server timer activity setting:off
```

  </Tab>
</Tabs>

When enabled, bored only dispatches a timer message if the channel had chat activity within the last `30` minutes.
