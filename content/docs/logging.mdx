Logging sends detailed server activity events (deletes, edits, member leaves, role modifications, channel creation, audit logs) to your chosen staff channels.

## Quickstart

```text
/logs setup
```

This creates a private `logs` category hidden from `@everyone` with dedicated channels for messages, members, roles, channels, invites, emojis, voice, and moderation events.

## Supported events

* `messages` — deleted messages, edited messages, and bulk message purges.
* `members` — joins, leaves, nickname changes, and role assignments.
* `roles` — role creation, deletion, and permission updates.
* `channels` — channel creation, deletion, and topic/permission changes.
* `invites` — invite creation and deletion.
* `emojis` — custom emoji and sticker additions/removals.
* `voice` — connects, disconnects, and channel moves.
* `moderation` — audit log actions, kicks, and bans.

## View configuration

```text
/logs config
```

## Channel routing

### Add event to channel

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/logs channel add channel:<channel> [event:<event name>]
```

  </Tab>
  <Tab>

```text
/logs channel add channel:#logs event:messages
```

  </Tab>
</Tabs>

If you omit the event option, all logging events are bound to that channel.

### Remove event from channel

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/logs channel remove channel:<channel> [event:<event name>]
```

  </Tab>
  <Tab>

```text
/logs channel remove channel:#logs event:messages
```

  </Tab>
</Tabs>

## Event embed colors

Customize embed accent colors per event type:

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/logs channel color channel:<channel> event:<event> [color:<hex>]
```

  </Tab>
  <Tab>

```text
/logs channel color channel:#logs event:messages color:#ff3b30
```

  </Tab>
</Tabs>

## Ignored targets

Prevent noisy channels, spam bots, or testing categories from polluting your logs.

<Tabs items={["Add ignore", "Remove ignore", "List ignored"]}>
  <Tab>

```text
/logs ignore add [channel:#counting] [member:@spam-bot]
```

  </Tab>
  <Tab>

```text
/logs ignore remove [channel:#counting]
```

  </Tab>
  <Tab>

```text
/logs ignore list
```

  </Tab>
</Tabs>

## Reset logging

Wipes all logging channel routes and event configurations:

```text
/logs reset
```
