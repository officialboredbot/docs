bored provides a fast, full-featured moderation engine including instant timeouts, temporary jails, image/reaction mutes, hardbans, audit logs, and customizable punishment DMs.

## First-time setup

<Steps>
  <Step title="Configure the jail system">
    This creates the base jail system for the server.

```text
/setup system:jail
```

    bored creates or reuses `Jailed`, `#jail`, and `#jail-log`, and points the modlog channel at `#jail-log`.
  </Step>
  <Step title="Configure mute roles">
    This creates the saved roles used by bored's image mute and reaction mute commands.

```text
/setup system:mute
```

    bored creates or reuses `Image Muted` and `Reaction Muted`.
  </Step>
</Steps>

## Core moderation commands

### Ban & Unban

<Tabs items={["Ban", "Hardban", "Unban", "Unban All"]}>
  <Tab>

```text
/ban member:@member [delete_history:1d] [reason:violating rules] [silent:true]
```

  </Tab>
  <Tab>

```text
/ban member:@member hard:true [reason:persistent raider]
```

Hardbanning immediately re-bans the member if anyone attempts to unban them in the future.

  </Tab>
  <Tab>

```text
/unban member:@user [reason:appeal accepted]
```

  </Tab>
  <Tab>

```text
/unban unbanall:true
```

  </Tab>
</Tabs>

### Kick

```text
/kick member:@member [reason:disruptive behavior] [silent:true]
```

### Timeout

Apply Discord's native timeout to temporarily mute and restrict a member.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/timeout member:<user> [duration:<duration>] [reason:<reason>] [silent:<true or false>]
```

  </Tab>
  <Tab>

```text
/timeout member:@member duration:1h reason:excessive toxicity silent:true
```

  </Tab>
</Tabs>

### Jail & Unjail

Jailing strips the member's assignable roles, confines them to `#jail` or a private jail thread, and restores their roles upon release.

<Tabs items={["Jail", "Unjail"]}>
  <Tab>

```text
/jail member:@member [duration:2h] [reason:raiding chat] [silent:true]
```

  </Tab>
  <Tab>

```text
/jail member:@member unjail:true
```

  </Tab>
</Tabs>

### Warn

Issue an official tracked warning with automatic case logging and punishment thresholds:

```text
/warn member:@member reason:advertising in general [silent:true]
```

## Role management & transfers

### Role transfer

Transfer every role from one member to another in a single bulk operation.

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/role transfer member:<source user> target:<destination user>
```

  </Tab>
  <Tab>

```text
/role transfer member:@OldAccount target:@NewAccount
```

  </Tab>
</Tabs>

### Role confirmation prompt

Toggle whether bored prompts for confirmation when fuzzy-matching role names:

```text
/role confirm setting:<on or off>
```

## Channel lockdown

Quickly lock down the entire server during a security emergency:

<Tabs items={["Lock All", "Unlock All"]}>
  <Tab>

```text
/lockdown lockall [reason:security containment]
```

  </Tab>
  <Tab>

```text
/lockdown unlockall [reason:threat neutralized]
```

  </Tab>
</Tabs>

## Server moderation settings

### Jail destination

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/settings jail channel:<channel>
```

  </Tab>
  <Tab>

```text
/settings jail channel:#staff-jail
```

  </Tab>
</Tabs>

### Private jail threads

Toggle private thread mode for jailed members:

```text
/settings jailthreads setting:<on or off>
```

### Modlog channel

```text
/settings modlog [channel:<channel>]
```

### Appeal server

Link an external appeal server button into all punishment DMs:

```text
/settings appealserver invite:https://discord.com/invite/your-appeal-server
```

### Silent moderation actions

Every punishment command supports `silent:true` to execute the punishment, write audit cases, and log to modlog without sending a direct message to the punished user.
