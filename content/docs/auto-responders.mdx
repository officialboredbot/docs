Auto Responders let bored watch for message triggers and automatically send a saved reply, assign roles, strip roles, or combine those actions together.

By default, triggers use **strict match** (the full message must match exactly).

## Add an autoresponder

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/autoresponder add trigger:<text> response:<text or embed> [not_strict:<on or off>] [self_destruct:<seconds>] [delete_trigger:<on or off>] [reply:<on or off>] [ignore_command_check:<on or off>]
```

  </Tab>
  <Tab>

```text
/autoresponder add trigger:welc response:Welcome to the server! reply:on self_destruct:10
```

  </Tab>
</Tabs>

### Trigger options

* **Loose match (`not_strict`)**: Matches anywhere inside a message rather than requiring the message to match the trigger word alone.
* **Auto delete response (`self_destruct`)**: Deletes the bot's reply automatically after `6` to `60` seconds.
* **Delete original trigger (`delete_trigger`)**: Deletes the member's message that tripped the autoresponder.
* **Reply format (`reply`)**: Sends the response as a direct message reply instead of a standalone channel post.
* **Ignore command check (`ignore_command_check`)**: Allows the trigger to fire even if the message begins with a bot command prefix.

## Channel & role exclusivity

Restrict an autoresponder so it only triggers in specific channels or for members with specific roles:

<Tabs items={["Toggle exclusive", "List exclusive"]}>
  <Tab>

```text
/autoresponder exclusive toggle trigger:welc [channel:#general] [role:@Member]
```

  </Tab>
  <Tab>

```text
/autoresponder exclusive list trigger:welc
```

  </Tab>
</Tabs>

## Role actions on trigger

### Grant role on trigger

Automatically award a role when a user says the trigger phrase:

<Tabs items={["Add role", "List added roles"]}>
  <Tab>

```text
/autoresponder role add role:@Verified trigger:verify
```

  </Tab>
  <Tab>

```text
/autoresponder role addlist trigger:verify
```

  </Tab>
</Tabs>

### Strip role on trigger

Automatically remove a role when a user says the trigger phrase:

<Tabs items={["Remove role", "List removed roles"]}>
  <Tab>

```text
/autoresponder role remove role:@Unverified trigger:verify
```

  </Tab>
  <Tab>

```text
/autoresponder role removelist trigger:verify
```

  </Tab>
</Tabs>
