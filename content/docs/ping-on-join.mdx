Ping on Join sends a ghost ping mentioning new members when they join, automatically deleting the ping message shortly after to notify them without cluttering the chat.

The default deletion delay is **5 seconds** (configurable between **3** and **10** seconds). Rapid joins in the same channel are batched into a single ping message.

## Add a channel

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/welcome pingonjoin add target:<channel>
```

  </Tab>
  <Tab>

```text
/welcome pingonjoin add target:#welcome
```

  </Tab>
</Tabs>

You can configure up to `7` channels per server.

## View configured channels

```text
/welcome pingonjoin list
```

## Remove a channel

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/welcome pingonjoin remove target:<channel>
```

  </Tab>
  <Tab>

```text
/welcome pingonjoin remove target:#welcome
```

  </Tab>
</Tabs>

## Adjust deletion delay

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/welcome pingonjoin time seconds:<seconds>
```

  </Tab>
  <Tab>

```text
/welcome pingonjoin time seconds:7
```

  </Tab>
</Tabs>

Delay must be between `3` and `10` seconds.

## Test & Reset

<Tabs items={["Test ping", "Reset all"]}>
  <Tab>

```text
/server pingonjoin test
```

  </Tab>
  <Tab>

```text
/welcome pingonjoin reset
```

  </Tab>
</Tabs>
