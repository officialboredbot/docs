Counter channels display dynamic server statistics directly in channel or category titles. They automatically update member metrics, channel totals, boost counts, or live countdown timers to a Unix timestamp.

Managing counters requires `Manage Channels`. The bot must also possess permissions to create and rename channels.

## Add a counter

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/server counter add metric:<string> channel_type:<string>
```

  </Tab>
  <Tab>

```text
/server counter add metric:members channel_type:voice
```

  </Tab>
</Tabs>

bored creates the managed channel immediately and keeps its name synchronized with live server activity.

## Supported metrics

Available metrics for `metric`:
- `members` - Total guild members
- `users_only` - Human members only
- `bots_only` - Bot accounts only
- `pending_members` - Members pending membership screening
- `all_channels` - Total guild channels
- `text_channels` - Text channels
- `voice_channels` - Voice channels
- `categories` - Category channels
- `announcement_channels` - Announcement channels
- `staging_channels` - Stage channels
- `boosts` - Current server boost count
- `booster_count` - Distinct server booster member count
- `<timestamp>` - Unix epoch timestamp (renders a live countdown)

Supported channel types for `channel_type`: `voice`, `text`, `category`, `announce`, `stage`.

## Remove a counter

<Tabs items={["Syntax", "Example"]}>
  <Tab>

```text
/server counter remove channel:<channel>
```

  </Tab>
  <Tab>

```text
/server counter remove channel:#members-1200
```

  </Tab>
</Tabs>

Removing a counter unregisters it from background sync routines without deleting the channel.

## List active counters

Inspect all active counters tracked in the guild.

```text
/server counter list
```
