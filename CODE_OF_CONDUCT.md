# bored documentation code of conduct

The bored documentation project should be a respectful place to ask questions,
share corrections, and collaborate on clearer technical writing.

## Expected behavior

Participants are expected to:

- Treat other contributors with patience and respect.
- Give feedback about the work rather than attacking the person.
- Explain disagreements clearly and assume good faith.
- Protect private information and avoid posting credentials, tokens, or
  private conversations.
- Accept moderation decisions and move discussions to a calmer setting when
  needed.

## Unacceptable behavior

Harassment, hate speech, threats, personal attacks, deliberate disruption,
unwanted sexual attention, and publishing someone else's private information
are not acceptable. This also includes disguising abuse as a joke or using
issues and pull requests to target another person.

## Enforcement

Project maintainers may edit, close, or remove contributions that violate this
standard, and may restrict participation when necessary to protect the
community. Decisions should be proportionate, consistent, and explained when
doing so does not create a further safety or privacy concern.

Report a concern privately through the
[bored support server](https://discord.com/invite/UePr2KBcFY). Please include
the relevant link or context and avoid reposting sensitive details publicly.
Reports will be handled as discreetly as possible.
