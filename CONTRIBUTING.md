# Contributing

We welcome corrections and improvements to bored's documentation.

Most changes belong in `content/docs`. Check the existing page before editing
it and make sure examples match bored's current behavior.

For larger changes, open an issue first so the structure can be discussed.

## Pull requests

1. Fork the repository and create a branch.
2. Make the change and keep it focused.
3. Run `bun install` and `bun run build`.
4. Open a pull request with a short description.

Screenshots are welcome when they help explain a feature. Add them under
`public/images` and include useful alt text. Please make sure you take these screenshots on the official Discord client, with no modified plugins. Theme must be Discord's official official "Onyx" theme. Screenshots must be of good quality.

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) before contributing.
