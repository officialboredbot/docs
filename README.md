# bored documentation

This repository contains the source for
[bored's documentation](https://docs.bored.rest/).

The site uses Next.js, [Fumadocs](https://fumadocs.dev), and MDX. Documentation pages are in
`content/docs`.

We welcome corrections and improvements. Please read
[CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request.

## Development

```bash
bun install
bun run dev
```

Run `bun run build` before opening a pull request.
